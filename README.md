# MeshMesh (форк)

Оригинальный проект: **[IKrasnodymov/meshmesh](https://github.com/IKrasnodymov/meshmesh)** —
автономная прошивка MeshCore-сети для ESP32/nRF52 и приложение для Android. Описание возможностей,
поддерживаемые платы, установка, сборка, языки и документация — в оригинале, здесь не дублируются.

Эта версия — набор фиксов и твиков для **мобильного приложения** и плат **Heltec V4** поверх оригинала.

## Отличия от оригинала

- **Импорт контакта по ссылке `meshcore://`** — «Добавить чат» в приложении и на странице устройства:
  вставьте ссылку (или hex-визитку) — контакт появляется в списке; список чатов разделён на табы
  «Чаты | Каналы».
- **Контекстное меню сообщения в приложении** — тап по сообщению в любом месте строки (область
  нажатия на всю ширину) открывает меню «Ответить» / «Путь пакета». «Ответить» вставляет в поле
  ввода тег `@[имя] ` (упоминание формата MeshCore), «Путь пакета» — маршрут сообщения, как раньше.
- **Хопы под моими сообщениями в приложении** — под галочками и временем показано, сколько хопов
  прошёл маршрут: «→ 2 хопа» или «→ напрямую».
- Команда `import` добавлена в список команд приложения (совместимость со старой прошивкой).

Проверяется на **Heltec V4**. Полный список изменений — в `git log` ветки `feature/contacts-import`.
